# Mods

> Changes to Claude Code's own interface and behaviour, installable in one line.

This repo is a Claude Code plugin marketplace (`.claude-plugin/marketplace.json`), so each mod installs with:

```
/plugin install <mod> --marketplace datnguyen79/Dstack
```

## Mods

| Mod | What it does |
|-----|--------------|
| [quote-reply](./quote-reply/README.md) | Highlight Claude's reply to quote it into your prompt; multi-quote + Clear quote button |
